# SHUT на Android

Приложение — тот же сайт SHUT, упакованный через Capacitor (как и iOS-версия): то же шифрование, та же фраза, та же синхронизация. Файлы сайта лежат внутри приложения, поэтому оно работает офлайн.

Сверх сайта в приложении есть:
- **Вход по отпечатку** (или надёжному распознаванию лица). Ключ сейфа шифруется ключом из Android Keystore, который открывается только биометрией. Если добавить в телефон новый отпечаток, сохранённый ключ сбрасывается, и нужно один раз войти по мастер-паролю. Сам мастер-пароль не сохраняется.
- **Сразу экран входа** вместо лендинга.
- **Напоминания о событиях** — уведомления самого телефона, без сервера. При первом запуске Android спросит разрешение на уведомления.
- **Кнопка «Назад»** закрывает открытое окно или карточку, а на главном экране сворачивает приложение.
- Данные приложения не попадают в облачные копии Google.

## Как получить APK (ничего ставить не нужно)

APK собирается автоматически на серверах GitHub после каждого пуша в `main` (файл `.github/workflows/android.yml`).

1. На телефоне откройте страницу релиза: https://github.com/noname15092025-ctrl/seif/releases/tag/android-latest
2. Скачайте **SHUT.apk** и откройте его.
3. Android попросит разрешить установку из этого источника (браузера или «Файлов») — разрешите.
4. Новая версия ставится так же, поверх старой. Данные сохраняются.

Запустить сборку вручную: на GitHub → **Actions** → **Android APK** → **Run workflow**.

## Ключ подписи

Android ставит обновление поверх старой версии, только если оба APK подписаны **одним и тем же ключом**. Ключ хранится в секретах репозитория (Settings → Secrets and variables → Actions):
- `SHUT_KEYSTORE_B64` — файл ключа (PKCS12) в base64;
- `SHUT_KEYSTORE_PASSWORD` — пароль;
- `SHUT_KEY_ALIAS` — имя ключа.

Без этих секретов собирается отладочный APK. Каждая такая сборка подписана случайным ключом, поэтому обновить её поверх нельзя — только удалить старую (вместе с данными на телефоне) и поставить новую.

**Сохраните копию ключа в надёжном месте.** Если его потерять, следующие версии придётся ставить начисто. В Google Play с этим ключом тоже можно будет публиковаться.

## Сборка на своём компьютере (необязательно)

Нужны Node.js (LTS), JDK 17 и Android Studio.
```bash
npm install
npm run android:setup     # создаёт android/, иконки, копирует сайт и плагины
npm run android:open      # открыть в Android Studio → Run
```
После изменений сайта: `npm run android:sync`.

## Google Play

Для публикации нужен аккаунт разработчика Google Play (разовый взнос $25) и сборка в формате `.aab` (`./gradlew bundleRelease` в папке `android/`) с тем же ключом подписи.
