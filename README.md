# Vault

Zero-knowledge менеджер паролей в браузере. Всё шифруется на вашем устройстве, сервера нет.

- Секретная фраза из 12 слов (BIP39) — единственный способ восстановить хранилище.
- Мастер-пароль — для повседневного входа на устройстве.
- Шифрование AES-256-GCM, ключи через PBKDF2 / HKDF (Web Crypto).
- Данные хранятся только в `localStorage` в зашифрованном виде; резервная копия — зашифрованный JSON.

**Если потеряны и пароль, и фраза — восстановить доступ невозможно. Разработчик тоже не может помочь.**

## Запуск

Откройте `index.html` в браузере или через GitHub Pages.

## Планы

- Встроить словарь BIP39 в файл (полностью офлайн)
- Argon2id вместо PBKDF2
- Мобильное приложение
