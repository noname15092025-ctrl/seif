# Vault

Zero-knowledge менеджер паролей в браузере. Всё шифруется на вашем устройстве, сервера нет.

**Сайт:** https://noname15092025-ctrl.github.io/seif/

## Возможности
- Секретная фраза из 12 слов (BIP39) — единственный способ восстановить профиль
- Мастер-пароль защищён **Argon2id** (19 МиБ, 2 прохода), данные — **AES-256-GCM**
- Типы записей: пароли, заметки, банковские карты, Wi-Fi
- Категории, избранное, поиск, фильтры, сортировка, редактирование
- Генератор паролей (символы или слова), индикатор надёжности
- Коды 2FA (TOTP)
- Аудит: слабые, повторяющиеся, старые пароли, проверка утечек (Have I Been Pwned, k-anonymity)
- Импорт CSV/Excel (Chrome, Firefox, Bitwarden, KeePass, 1Password), выгрузка в Excel
- Несколько профилей, ограничение попыток входа, автоблокировка
- PWA: установка как приложение, работа без интернета
- Тёмная и светлая тема, русский и английский

**Если потеряны и пароль, и фраза — восстановить доступ невозможно. Разработчик тоже не может помочь.**

## Файлы
- `index.html`, `style.css`, `app.js` — приложение
- `argon2.js`, `argon2-worker.js` — Argon2id и BLAKE2b, проверяются по тестовым векторам RFC 9106 при каждом запуске
- `wordlist.js` — официальный словарь BIP39 (проверяется по SHA-256)
- `sw.js`, `manifest.webmanifest` — PWA

## Чем Vault отличается от обычных менеджеров

| | Обычные менеджеры | Vault |
|---|---|---|
| Где хранятся данные | На серверах компании | Только на вашем устройстве |
| Что можно украсть у сервиса | Зашифрованные хранилища (как у LastPass) | Нечего — сервера нет |
| Аккаунт и email | Нужны | Не нужны |
| Цена | Подписка, цены растут | Бесплатно навсегда |
| Восстановление | Через аккаунт и почту | По фразе из 12 слов |
| Слежка | Телеметрия и трекеры | Ноль внешних запросов |
| Код | Часто закрытый | Открытый, одна страница, работает офлайн |

Ниша Vault — максимум приватности и независимости (как KeePass, но с восстановлением по фразе и современным интерфейсом). Коммерческие менеджеры (1Password, Bitwarden, Dashlane, Keeper, NordPass, Proton Pass и др.) пока впереди по автосинхронизации, автозаполнению в браузере и passkeys.
