# SHUT на iPhone — сборка приложения (Capacitor)

Этот проект оборачивает готовый сайт SHUT в нативное iOS-приложение.
Весь код (шифрование, фраза восстановления, синхронизация) — тот же, что на сайте.
Приложение грузит те же файлы локально, поэтому работает офлайн и так же «ноль знаний».

Сверх сайта в приложении есть:
- **Вход по Face ID / Touch ID.** Ключ сейфа хранится в Keychain iPhone и открывается только биометрией.
- **Сразу экран входа** вместо лендинга. После блокировки тоже открывается экран входа.
- **Иконка и заставка** под все размеры iOS, светлый текст статус-бара на тёмном фоне.

## Что понадобится

1. **Mac** с установленным **Xcode** (бесплатно из Mac App Store).
2. **Node.js** (LTS) — https://nodejs.org
3. **CocoaPods**: в терминале `sudo gem install cocoapods`
4. **Аккаунт Apple Developer** — $99/год — нужен ТОЛЬКО для публикации в App Store.
   Чтобы просто собрать и поставить на свой айфон для теста, хватит бесплатного Apple ID.

> Собрать `.ipa` и залить в App Store можно только на Mac с Xcode — из других сред (включая Windows) нельзя.

## Шаги (выполняются на Mac, в папке проекта)

### 1. Склонировать репозиторий и поставить зависимости
```bash
git clone https://github.com/noname15092025-ctrl/seif.git
cd seif
npm install
```

### 2. Создать iOS-проект (один раз)
```bash
npm run ios:setup
```
Команда делает всё по порядку:
1. собирает `www/` из файлов сайта;
2. создаёт нативный проект в `ios/` (`npx cap add ios`);
3. генерирует иконки и заставки из `assets/` (`@capacitor/assets`);
4. копирует сайт и плагины в приложение (`npx cap sync ios`);
5. вписывает в `Info.plist` текст запроса Face ID и стиль статус-бара (`scripts/ios-patch.mjs`).

### 3. Открыть в Xcode
```bash
npm run ios:open           # то же, что npx cap open ios
```
В Xcode:
- Слева выбрать проект **App** → вкладка **Signing & Capabilities**.
- **Team** → выбрать свой Apple ID (Xcode → Settings → Accounts → «+» → войти).
- **Bundle Identifier** оставить `app.shut.wallet` (или свой уникальный).

### 4. Запустить на айфоне
- Подключить iPhone кабелем, выбрать его вверху как устройство.
- Нажать ▶️ (Run). Первый раз на айфоне: Настройки → Основные → Управление VPN и устройствами → доверять своему профилю разработчика.

### 5. Проверить Face ID
Face ID работает только на настоящем айфоне. В симуляторе он есть в меню Features → Face ID.
1. Создать сейф или войти по мастер-паролю. Приложение спросит «Открывать сейф по Face ID?» → **Включить**.
2. Нажать замок, чтобы заблокировать сейф. На экране входа появится кнопка **«Войти по Face ID»**.
3. Свернуть приложение больше чем на минуту и вернуться: сейф заблокирован, Face ID запросится сам.
4. Настройки → «Приложение» → переключатель **«Вход по Face ID»**. Если его выключить, ключ удаляется из Keychain.

### 6. Публикация в App Store (когда будешь готов)
- Нужен платный аккаунт Apple Developer.
- В Xcode: **Product → Archive** → **Distribute App** → App Store Connect.
- Заполнить карточку в App Store Connect (название, скриншоты, описание, политика конфиденциальности).
- На вопрос про шифрование (Export Compliance) ответить честно: приложение использует стандартное шифрование (AES-GCM, Argon2id).
- Отправить на ревью (обычно 1–3 дня).

## Когда обновил сайт — как обновить приложение
После любых правок в коде сайта:
```bash
git pull
npm install                # если менялся package.json
npm run ios:sync           # build:www + cap sync ios + патч Info.plist
```
Затем в Xcode снова Run (для теста) или Archive (для новой версии в App Store).
Если поменялась иконка в `assets/`, выполни `npm run ios:assets`.

## Как устроен Face ID (безопасность)

- В Keychain хранится **ключ сейфа** (32 байта AES), а **не мастер-пароль**. Мастер-пароль на устройстве не хранится нигде.
- Запись создаётся с флагами `kSecAttrAccessibleWhenPasscodeSetThisDeviceOnly` и `.biometryCurrentSet`:
  - достать ключ можно только после успешного Face ID / Touch ID, это проверяет сама iOS (Secure Enclave), а не JavaScript;
  - если на телефоне нет код-пароля, Face ID не включится;
  - запись не попадает в резервные копии iCloud и на другие устройства;
  - если в телефон добавят новое лицо или палец, запись становится недействительной. Приложение попросит один раз войти по паролю и снова предложит Face ID.
- Код-пароль телефона как запасной вариант отключён: запасной путь — только мастер-пароль.
- Плагин лежит в `native/shut-keychain/` (Swift, около 110 строк). Его подключает `npm install`, а `cap sync` добавляет в Xcode-проект.

## Что лежит в репозитории
- `package.json` — зависимости Capacitor, плагины и скрипты `ios:*`.
- `capacitor.config.json` — appId `app.shut.wallet`, имя **SHUT**, тёмный фон `#121212`, заставка, статус-бар. `contentInset: never`: отступы под чёлку делает CSS через `env(safe-area-inset-*)`.
- `native/shut-keychain/` — локальный плагин Keychain + Face ID.
- `assets/` — исходники иконки (`icon-only.png`, 1024×1024) и заставки (`splash.png`, `splash-dark.png`, 2732×2732).
- `scripts/build-www.mjs` — собирает `www/` только из нужных файлов (без .git, инструкций и кода воркеров).
- `scripts/ios-patch.mjs` — дописывает в `Info.plist` строку `NSFaceIDUsageDescription` (без неё iOS не даст включить Face ID) и стиль статус-бара.
- `.gitignore` — исключает `node_modules/`, `www/` и папку `ios/`. Её целиком генерирует `npm run ios:setup`.
