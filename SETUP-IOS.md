# SHUT на iPhone — сборка приложения (Capacitor)

Этот проект оборачивает готовый сайт SHUT в нативное iOS-приложение.
Весь код (шифрование, фраза восстановления, синхронизация) — тот же, что на сайте.
Приложение грузит те же файлы локально, поэтому работает офлайн и так же «ноль знаний».

## Что понадобится

1. **Mac** с установленным **Xcode** (бесплатно из Mac App Store).
2. **Node.js** (LTS) — https://nodejs.org
3. **CocoaPods**: в терминале `sudo gem install cocoapods`
4. **Аккаунт Apple Developer** — $99/год — нужен ТОЛЬКО для публикации в App Store.
   Чтобы просто собрать и поставить на свой айфон для теста, хватит бесплатного Apple ID.

> Собрать `.ipa` и залить в App Store можно только на Mac с Xcode — из других сред (включая эту) нельзя.

## Шаги (выполняются на Mac, в папке проекта)

### 1. Склонировать репозиторий и поставить зависимости
```bash
git clone https://github.com/noname15092025-ctrl/seif.git
cd seif
npm install
```

### 2. Собрать веб-папку и добавить платформу iOS (один раз)
```bash
npm run build:www          # собирает www/ из файлов сайта
npx cap add ios            # создаёт нативный проект в папке ios/
npx cap sync ios           # копирует www/ внутрь приложения
```

### 3. Открыть в Xcode
```bash
npm run ios:open           # то же, что npx cap open ios
```
В Xcode:
- Слева выбрать проект **App** → вкладка **Signing & Capabilities**.
- **Team** → выбрать свой Apple ID (Xcode → Settings → Accounts → «+» → войти).
- **Bundle Identifier** оставить `app.shut.wallet` (или свой уникальный).

### 4. Запустить на айфоне
- Подключить iPhone кабелем, выбрать его вверху как устройство.
- Нажать ▶️ (Run). Первый раз на айфоне: Настройки → Основные → Управление VPN и устройствами → доверять своему профилю разработчика.

### 5. Публикация в App Store (когда будешь готов)
- Нужен платный аккаунт Apple Developer.
- В Xcode: **Product → Archive** → **Distribute App** → App Store Connect.
- Заполнить карточку в App Store Connect (название, скриншоты, описание, политика конфиденциальности).
- Отправить на ревью (обычно 1–3 дня).

## Когда обновил сайт — как обновить приложение
После любых правок в коде сайта:
```bash
git pull
npm run ios:sync           # build:www + cap sync ios
```
Затем в Xcode снова Run (для теста) или Archive (для новой версии в App Store).

## Что уже настроено в репозитории
- `package.json` — зависимости Capacitor и скрипты.
- `capacitor.config.json` — appId `app.shut.wallet`, имя **SHUT**, тёмный фон `#121212`.
- `scripts/build-www.mjs` — собирает `www/` только из нужных файлов (без .git, инструкций и кода воркеров).
- `.gitignore` — исключает `node_modules/`, `www/`, папку `ios/`.
