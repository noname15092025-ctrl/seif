# Синхронизация между устройствами — настройка (≈5 минут, бесплатно)

Облако хранит только **зашифрованный** сейф. Сервер не видит паролей, ключей и содержимого.

## Вариант: Cloudflare Workers (бесплатно, без карты)

1. Зарегистрируйся на https://dash.cloudflare.com (бесплатно).
2. Слева: **Workers & Pages** → **Create** → **Create Worker** → имя, например `vault-sync` → **Deploy**.
3. Открой воркер → **Edit code**, удали весь код и вставь содержимое файла `sync-worker.js` из этого репозитория → **Deploy**.
4. Создай хранилище KV: **Storage & Databases → KV → Create** namespace, имя `vault`.
5. Привяжи его к воркеру: воркер → **Settings → Bindings → Add → KV namespace**:
   - Variable name: `VAULT`
   - KV namespace: выбери `vault`
   - **Deploy**.
6. Скопируй адрес воркера (вида `https://vault-sync.ТВОЙ-АККАУНТ.workers.dev`).
7. В приложении: **Настройки и копии → Синхронизация** → вставь адрес → **Сохранить** → **Синхронизировать сейчас**.
8. На другом устройстве/браузере: открой сайт → **«У меня есть фраза»** → введи 12 слов (файл копии не нужен — сейф подтянется из облака) → задай локальный пароль.

Готово: сейф синхронизируется между устройствами, оставаясь зашифрованным.

## Как это защищено
- Сейф шифруется на устройстве (AES-256-GCM) ключом из твоей секретной фразы.
- Идентификатор и токен доступа к облаку выводятся из той же фразы (HKDF) — только владелец фразы может читать/писать.
- Сервер хранит шифротекст и хеш токена. Даже при полной компрометации сервера расшифровать сейф нельзя.
- Разрешение в CSP: только `*.workers.dev` (Cloudflare). Для своего домена добавь его в `connect-src`.

## Ограничение версии 1
- Разрешение конфликтов — «последняя запись побеждает» по времени. Если редактировать офлайн на двух устройствах одновременно, более поздняя перезапишет более раннюю. Для одного пользователя это обычно безопасно.
